# 无障碍 / Accessibility

[简体中文](#简体中文) · [English](#english)

## 简体中文

LumaRecode 使用 WinUI 3 和 SwiftUI 提供各平台的原生控件。Windows 提供高对比度主题适配。逐帧预览可用左右方向键选帧，用 Esc 关闭。两端也提供[命令行](docs/README.md#使用指南)，可完成素材检查和转码。

屏幕阅读器在各工作流程中的覆盖仍待核验。若你遇到无障碍问题，可提交 [GitHub Issue](https://github.com/MIKU552/LumaRecode/issues/new/choose) 或联系 <lumarecode@miku552.top>。请注明应用版本、系统版本、使用的辅助技术和遇到问题的操作。

## English

LumaRecode uses native WinUI 3 and SwiftUI controls on their respective platforms. Windows supports the system's contrast themes. In the Windows frame preview, arrow keys step through frames and Esc closes the overlay. Both platforms also offer a [command-line interface](docs/README.md#user-guides) for inspecting and converting media.

Screen reader coverage across all workflows still needs verification. Report accessibility barriers through [GitHub Issues](https://github.com/MIKU552/LumaRecode/issues/new/choose) or <lumarecode@miku552.top>. Include the app version, OS version, assistive technology and the action that caused difficulty.
