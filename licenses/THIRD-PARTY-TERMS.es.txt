FrameFlow — Condiciones de los componentes binarios de terceros

El código fuente, la documentación y los recursos originales de FrameFlow usan la licencia MIT. La distribución para Windows incluye entornos de ejecución de Microsoft y Python, OpenSSL y la LUT de OpenOSV, cada uno con sus propias licencias y avisos.

Al elegir «Aceptar y continuar», aceptas cumplir las condiciones aplicables a los componentes de terceros incluidos: Windows App SDK, la .NET Library License para los binarios de ejecución de Windows designados (incluido el entorno de ejecución de archivo único), las condiciones del SDK de Windows para los ensamblados de proyección de WinRT y las del código redistribuible de Microsoft en la compilación binaria oficial de Python para Windows. Los textos completos de las licencias, los avisos y los registros de los paquetes de origen se encuentran en este mismo directorio licenses.

En particular, conserva los avisos de derechos de autor, marcas y patentes de Microsoft; no sugieras el respaldo de Microsoft; utiliza los componentes binarios de Windows en sistemas operativos, tecnologías de ejecución o plataformas de aplicaciones de Microsoft conforme a sus condiciones; y no los incluyas en programas maliciosos, engañosos o ilegales. No modifiques ni redistribuyas los componentes de Microsoft salvo en los casos permitidos por sus condiciones. Si redistribuyes un programa que los contiene, conserva los avisos necesarios y obtén la aceptación de los destinatarios que exijan dichas condiciones. Las condiciones adicionales para la compilación binaria de Windows figuran en Python-LICENSE.txt; los derechos y requisitos de redistribución de Windows App SDK figuran en los textos de licencia de los paquetes correspondientes.

La .NET Library License establece las condiciones para distribuir código objeto como parte de esta aplicación. La lista REDIST del SDK de Windows incluye los archivos sin modificar del paquete Microsoft.Windows.SDK.NET.Ref utilizados para llamar a las API de WinRT. Consulta DotNet-Library-LICENSE.html, Windows-SDK-Net-Ref-LICENSE.rtf y Windows-SDK-REDIST.html. Lee las condiciones completas, incluidas sus limitaciones de uso, redistribución, avisos y disposiciones aplicables sobre recopilación de datos.
