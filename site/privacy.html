Privacy

Files and settings

LumaRecode processes the media you open on your device. The app has no account service, uploads no media to the developer, and sends no analytics. It stores preferences and tool paths locally. Your exports go to the location you select.

Support

Conversion logs can contain file paths and media information. Review them before sharing. If you email lumarecode@miku552.top, the maintainer uses the address and information you send to respond to your request. GitHub issues on the public repository are visible to other visitors.

Website

This site uses GitHub Pages and contains no analytics scripts or tracking cookies. The site saves your language and appearance choices in your browser. GitHub records visitor IP addresses for security. Read the GitHub privacy statement for hosting and GitHub interactions.

隐私

文件与设置

映码在你的设备上处理所打开的素材。应用没有账号服务，不向开发者上传素材，也不发送使用统计。应用在本地保存偏好和工具路径，并把结果导出到你选择的位置。

问题反馈

转换日志可能包含文件路径和素材信息，分享前请先检查。你向 lumarecode@miku552.top 发邮件时，维护者使用你的地址和邮件内容回复问题。公开仓库中的 GitHub Issue 可被其他访客看到。

项目网站

网站托管于 GitHub Pages，没有统计脚本或追踪 Cookie。手动选择的语言和外观保存在你的浏览器中。GitHub 出于安全目的记录访客的 IP 地址。网站托管及 GitHub 交互详情见 GitHub 隐私声明（英文）。

プライバシー

ファイルと設定

LumaRecode は、開いた素材をお使いの端末で処理します。アカウントサービスはなく、開発者への素材のアップロードや利用統計の送信は行いません。設定とツールのパスは端末内に保存され、書き出し先は利用者が選択します。

お問い合わせ

変換ログにファイルパスや素材の情報が含まれることがあります。共有する前に内容を確認してください。lumarecode@miku552.top へのお問い合わせでは、返信に必要な範囲でメールアドレスと送信内容を使用します。公開リポジトリの GitHub Issues は他の利用者も閲覧できます。

ウェブサイト

このサイトは GitHub Pages を利用し、アクセス解析スクリプトやトラッキング Cookie を使用しません。手動で選んだ言語と外観はブラウザーに保存されます。GitHub はセキュリティのためにアクセス元の IP アドレスを記録します。詳細は GitHub のプライバシーステートメントをご覧ください。

Privacidad

Archivos y ajustes

LumaRecode procesa en tu dispositivo el material que abres. La aplicación no usa cuentas, no envía material al desarrollador y no transmite datos de uso. Guarda localmente las preferencias y las rutas a las herramientas. Los archivos se exportan a la ubicación que elijas.

Contacto

Los registros de conversión pueden contener rutas de archivos e información del material. Revísalos antes de compartirlos. Si escribes a lumarecode@miku552.top, el responsable del proyecto usa tu dirección y la información que envíes para responder. Las incidencias de GitHub en el repositorio público son visibles para otras personas.

Sitio web

El sitio usa GitHub Pages y no usa scripts de análisis ni cookies de seguimiento. Tus elecciones de idioma y apariencia se guardan en tu navegador. GitHub registra las direcciones IP de los visitantes por motivos de seguridad. Consulta la declaración de privacidad de GitHub para conocer los detalles del alojamiento y las interacciones en GitHub.
